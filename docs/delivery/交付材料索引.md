# TestData Agent 正式交付文档与演示材料

发布日期 2026年10月31日　文档版本 1.1　产品版本 0.1.0

本包用于本地演示、项目接收和技术面试讲解，提供三份 PDF 正式文档、对应可编辑 Markdown 源稿、架构图、历史页面证据和验收摘要。它不是应用安装包，不包含项目测试源码或视频。

## 阅读顺序

1. 01 项目交付说明书：理解项目定位、架构、模块、技术、数据库、运行与安全限制。
2. 02 人工演示操作手册：按顺序操作并对照预期结果，使用讲解词和录屏分镜。
3. 03 项目验收记录表：区分通过、仅替身通过、未验证与阻塞，补录证据后签署。

## 文件目录

- 三份 PDF：正式阅读与发送版本，含章节导航。
- 源稿：三份 UTF-8 Markdown，可编辑和纳入版本管理。
- 配图：SVG、PNG、Mermaid 架构源图，当前蓝色工作台及历史人工报告、清洗截图。
- 证据：脱敏汇总 JSON、原始证据位置及 SHA-256。
- 演示数据：sample-data 的合成 CSV/XLSX、规则与独立预期副本，以及 demo-openapi.json。
- SHA256SUMS.txt：本包文件完整性清单。

## 当前结论

确定性接口测试、数据质量、清洗、接口导出和报告已有验证证据；Agent 受控闭环仅完成本机替身验收。真实模型成功链路、XLSX 页面上传、OpenAPI 完整页面提交、CSV/XLSX/HTML 浏览器实际落盘及完整视频仍待补齐。不能将文档完成写成全部最终验收通过。

后端与演示 API 最近一次完整回归为 54/54、4/4。本次只复核历史报告并核对运行入口，没有重跑全量测试。航天蓝主题之后的前端类型检查与生产构建通过。

本机当前入口为前端 5174、后端 8084、演示 API 8081；8080 保留给 AutoFlow。本包不要求切换或重启现有服务。

## 分发范围

不含真实密钥、密码、审批令牌、DPAPI配置、活动数据库、上传原文件、备份、完整日志、依赖目录、构建目录或临时替身。历史测试、原POM和临时验收资料已本地归档；公开源码不含测试源码及测试专用依赖。对外演示前由维护者本机完成审批凭据安全复核与轮换。

后续正式源码包须另行按白名单生成，不要将本机 .local-runtime 或 .runtime-acceptance 整体打包。本包的证据路径相对于原项目工作区，不表示已经包含对应应用源码或全部原始记录。

## 演示数据使用

演示数据/ 下的文件是项目 sample-data 的原样副本；demo-openapi.json 来自 demo-api/openapi.json。手册中的原工作区路径保持不变，使用本材料包时可从演示数据目录选择对应文件。dirty 文件按规则检测为 6 个问题，valid 为 0；清洗预期是修改 2 单元格、移除 1 重复行、输出 2 行，不能宣称已修复全部质量问题。
