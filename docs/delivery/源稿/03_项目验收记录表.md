## 一 验收范围与状态定义

本表汇总已有执行证据及本次文档编制的只读核对。后端与演示 API 测试数量来自 2026年10月31日保留的完整回归记录，本轮只重新核对报告，不冒充刚刚重跑。前端航天蓝主题构建为后续单独验证；人工页面运行与旧批量基线分别列出。

| 状态 | 定义 |
| --- | --- |
| 通过 | 在注明的环境与范围中，有实际代码测试或运行证据满足标准 |
| 仅替身通过 | 模型协议由本机替身产生；真实 HTTP 引擎和数据库可参与，不能代表真实模型效果 |
| 未验证 | 尚未执行所需步骤或缺少对应证据 |
| 阻塞 | 已尝试，但当前工具或环境阻止完成核验；不据此断定业务功能失败 |
| 失败 | 实际执行与验收标准不符；需记录复现证据和处理结果 |

“预期 FAIL”是测试引擎结果，不是本表的验收失败。一条故意错误断言得到 FAIL、证据正确且统计如实，属于验收通过。系统没有 XFAIL 免计入规则。

### 超时和审计限制

模型请求超时、工具创建任务的最大等待、单条 HTTP 测试超时是不同边界，不能相互替代。失败分析首个模型请求早于工具审计开始，其失败不一定有工具审计记录；证据工具 SUCCESS 也不表示第二轮分析成功。当前审计不是完整 AI 任务生命周期或账单台账。
