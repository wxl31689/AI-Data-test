## 公开版构建

本轮已在隔离源码副本分别运行后端和演示API的 `mvn -o -Dmaven.test.skip=true package`，均为 BUILD SUCCESS；前端使用已有依赖运行类型检查与生产构建，通过，产物写入隔离目录。没有切换现有服务。

新克隆目录先安装依赖：前端 `npm ci` 后 `npm run build`；后端和演示 API 使用 `mvn -Dmaven.test.skip=true package`。本轮没有从全新机器验证网络依赖安装。机器可读状态见 [构建记录](verification-baseline.json)。编译打包成功不等于重新执行原54/4项测试；复跑需在独立目录恢复测试源码及原POM。
